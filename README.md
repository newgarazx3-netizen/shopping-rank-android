# 쇼핑 노출순위 Android Viewer v0.1

- 운영 대시보드: https://shopping-rank-dashboard.vercel.app/
- 확인 전용 WebView 앱
- 판매처 확인 / 확장앱 연결 / 데이터 보관 관리 기능 숨김
- 순위 확인, 필터, 회차 비교, 상품 상세 열기 사용
